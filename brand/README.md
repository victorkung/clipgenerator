# Brand assets

Official clipgenerator marks and wordmarks for product UI and documentation.

| File | Use |
|------|-----|
| `favicon.svg`, `favicon-*.png` | Browser tab icons |
| `apple-touch-icon-180.png` | iOS home screen |
| `mark-*.svg` / `mark-512-transparent.png` | App mark (ink / paper / terracotta) |
| `logo-wordmark-on-*.svg` / `.png` | Wordmark on dark or light |
| `logo-lockup-with-tagline.png` | Marketing lockup |

The Vite app loads favicons from `app/frontend/public/` (copied from this folder for the build). Keep this `brand/` tree as the source of truth for README and marketing.
